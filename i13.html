Absolute root SVG diagnostic

This page compares getBoundingClientRect() with getBoxQuads() for an absolutely positioned root <svg>. In current Chromium and Firefox builds, this setup resolves computed left/top to pixel values, so it does not reproduce the earlier left/top: auto fallback path by itself. It is useful as a geometry visualizer, not as proof for the fallback fix.
